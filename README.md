# Personal Portfolio Website 🚀

This is a simple, semantic, and responsive personal portfolio webpage created using **HTML5**. This project was developed as part of the **Web Design Essentials** assignment under the **Entri Elevate AI-Enhanced MERN Full Stack Development** program.

## 📌 Project Overview
The goal of this project is to showcase my basic web development skills, including HTML structure, semantic tagging, and organizing content effectively for the web.

## 🛠️ Tech Stack
- **HTML5**: For structuring the content.
- **Semantic Tags**: Used for better SEO and accessibility.

## 📂 Sections Included
- **Header**: Contains my name and navigation links.
- **About Me**: A brief introduction about my journey as an aspiring Full Stack Developer.
- **Skills**: A list of technical skills I am currently mastering.
- **Projects**: Highlights of the initial web projects I've worked on.
- **Footer**: Credits and program details.
